## Purpose

Incrementally migrate verified live `apps/rms-web` operational modules onto approved FX foundations (shell, nav, dashboard, workspace, forms, tables) without changing business behavior.

## Non-goals

- New product modules
- Backend/API/schema/permission changes
- NERIS/CAD logic changes
- Legacy deletion (S2G)
- General availability

## Sequence

S2F-1 Incidents → S2F-2 Review → S2F-3 CAD Messages → S2F-4 Connections → S2F-5 Conflicts → S2F-6 NERIS Config → S2F-7 Admin/Utilities → S2F-8 Stabilization

Stop after each subphase unless continuous execution is recorded.
