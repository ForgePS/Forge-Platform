# DEC-S2-005 — Navigation Source of Truth

**Date:** 2026-07-30  
**Gate:** FX-S2B  
**Status:** ACCEPTED

## Decision

**Option C — Controlled Hybrid**

| Concern | Authority |
| --- | --- |
| Route path | Typed registry (`navigation.registry.ts`) |
| Route identifier | Typed registry |
| Permission / product feature-flag requirements | Typed registry |
| Deep-link behavior | Typed registry + existing routes |
| Component association | Existing Next.js pages (unchanged) |
| Labels, grouping, ordering, tenant presentation overlays | Configuration *may* override later when validated |

## Rationale

- Config Studio navigation is fetched today but **not wired** into the shell (S2A finding).
- Live routes are the only verified surface (16 pages).
- Hybrid preserves a code-owned contract for safety while allowing future tenant presentation tuning.

## Non-goals

- Do not invent Personnel/Fleet/Prevention nav groups.
- Do not treat Config Studio as authoritative until parity is proven.
