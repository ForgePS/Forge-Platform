# Pattern — Dashboard Personalization

**Last Updated:** 2026-07-30 · **Author:** FX Program

## Purpose

Move, collapse, and optionally resize dashboard widgets within FX rules.

## Scope

Executive/Operational/Personal/Module dashboards.

## Goals

Keyboard-operable layout edit; respect Creator/Tenant/role/subscription enablement.

## Examples

User collapses Weather; admin disables System Health for a role.

## Anti-patterns

Free-form pixel layouts; product-specific dashboard editors.

## Dependencies

Dashboard framework · Widget library · Accessibility.
