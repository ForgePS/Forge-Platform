# Pattern — Archive & Restore Record

**Last Updated:** 2026-07-30 · **Author:** FX Program

## Purpose
Soft end-of-life and recovery using shared workflow states Archived / Restore operation.

## Scope
Archive/Restore record operations.

## Goals
Clear status change; audit; restore path when permitted.

## Examples
Archive retired apparatus; restore mistaken archive.

## Anti-patterns
Using Delete when Archive is required by policy.

## Dependencies
Record operations · Workflow · Security UX.
