# Pattern — Wizard

**Last Updated:** 2026-07-30 · **Author:** FX Program

## Scope

## Goals
Announce steps; Validation Summary; draft recovery.

## Examples
Permit request wizard; academy enrollment steps.

## Anti-patterns
