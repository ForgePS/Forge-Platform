# Pattern — Delete Record

**Last Updated:** 2026-07-30 · **Author:** FX Program

## Purpose

Irreversible or policy-delete with confirmation and audit.

## Scope

Delete actions on records when permitted.

## Goals

Confirmation Dialog (destructive); reference consequences; audit entry.

## Examples

Delete draft document.

## Best practices

Prefer Archive when retention requires.

## Anti-patterns

Delete without confirm; silent delete.

## Dependencies

Actions · Workflow · Timeline/Audit.
