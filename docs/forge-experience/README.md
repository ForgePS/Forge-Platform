# Forge Experience (FX)

**Program:** Forge Experience (FX)  
**Version:** Design System v1.0.0-RC1 (FX-S1.5)  
**Status:** FX-S1.5 complete · FX-S2A inventory complete — awaiting approval for FX-S2B  
**Role:** Shared experience foundation for every Forge product

Forge Experience is **not** another application.  
It is the shared platform standard that defines how every Forge product looks, behaves, and feels.

**Reference app:** `apps/forge-experience-reference` (port 3010). See [reference/s1-status.md](./reference/s1-status.md).  
**RC1:** [VERSION.md](./VERSION.md) · Evidence: [evidence/](./evidence/) · Certification: [43-component-certification.md](./43-component-certification.md)  
**RMS migration:** [products/rms/](./products/rms/) · Registry: [44-component-registry.md](./44-component-registry.md)  
**Stop:** No FX-S2B shell work until FX-S2A completion report is formally approved.

## Products covered

- Forge RMS  
- Forge Academy  
- Forge Industrial Safety  
- Future Forge applications
