# Fire-Service Casualty Records

Table: `neris_incident_fire_service_casualties`.

- Separate permissions from ordinary incident edit (`rms.neris.fire_service_casualty.*`, `rms.neris.safety_review`)
- Personnel reference or documented unknown/external exception required
- Personnel display name snapshot preserved if employment changes
- Mayday requires details when selected
- List views are masked; full detail requires authorized view + access audit
- Not included in ordinary incident-list summaries
