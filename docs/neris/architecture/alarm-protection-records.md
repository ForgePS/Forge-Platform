# Alarm and Protection System Records

Tables: `neris_incident_alarm_systems`, `neris_incident_protection_systems`.

Each record covers system/device type, location, presence, activation, operation, effectiveness, impairment, failure reason, heads/devices activated (or unknown), manual intervention, contractor, corrective action, and inspection referral.

Validation enforces consistency between presence/operation, activated counts, failure reasons, and impairment dispositions.
