# Creator Console User Guide (Configuration)

Creator Console is the complete administration center for Forge platform tenants.

## Configuration Studio

Use **Configuration Studio** for all versioned configuration modules (profiles, branding, navigation, terminology, forms, workflows, templates, security, etc.).

Legacy pages **Legacy branding** and **Legacy key/value** remain for Sprint 1D `tenant_branding` / `tenant_settings` compatibility.

## Other areas

- Access: invitations, memberships, onboarding
- Platform: tenants, organizations, persons, users, roles, permissions
- Catalog: products, entitlements, subscriptions, feature flags
- NERIS Schema browsers
- AI Management (flags default off; synthetic acceptance only)

See also: [configuration-studio.md](./configuration-studio.md).
