# Renewal model

## List filters

Next 30 / 31–60 / 61–90 / 90+ days, Overdue, Auto Renew, Manual.

## Detail actions

- Renew As-Is
- Modify & Renew (price/module changes with preview)
- Generate Renewal Proposal (invoice draft)
- Schedule Cancellation

## Price changes

Show current, proposed, delta amount and percent. Require notes for increases. Scheduled future prices stored as pending changes until effective date.

## Jobs (idempotent)

Renewal reminders, scheduled cancellations, trial expiration, invoice past-due updates, scheduled module removals, dunning stage notifications (internal). External email delivery shows PENDING EMAIL SERVICE when SES is not production-ready.
