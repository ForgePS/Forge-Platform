# Access Reviews

Periodic attestation of privileged and sensitive access.

## Scope (initial)

- AWS IAM Identity Center / IAM privileged roles
- Cognito admin / elevated application roles
- Database admin credentials custodianship
- GitHub org/repo admin permissions
- Secrets Manager / KMS admin permissions

## Cadence

**Quarterly** (target) once procedure is approved.

Templates → `templates/`  
Completed reviews → `../evidence/access/` and dated folders here.

Related control: **CC-ACC-03** (currently Not operating).
